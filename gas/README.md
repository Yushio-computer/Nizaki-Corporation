# 【超初心者向け】神埼鉄道 LINE × GAS スタンプラリー連携 1から始める完全マニュアル

このガイドでは、プログラミングやAPI設定が初めての方でも、**手順通りに進めるだけでLINE公式アカウントからクーポンが自動返信されるシステム**を作ることができます。

---

## 🏁 全体の流れ（完成までの4つのステップ）

1. **【LINE側】** LINE Developersで「チャネルアクセストークン」を取得する
2. **【Google側】** Googleスプレッドシートを開いてGASコードを貼り付ける
3. **【GAS側】** トークンを入力して「ウェブアプリ」として公開（デプロイ）する
4. **【LINE側】** 発行されたURLをLINEに設定して連携完了！

所要時間：**約5〜10分**

---

## 🔷 ステップ1：LINE Developersでトークンを取得する

1. ブラウザで [LINE Developers Console](https://developers.line.biz/) を開きます。
2. お持ちのLINEアカウント（またはビジネスアカウント）でログインします。
3. すでに作成済みの「プロバイダー」または新規作成したプロバイダーを開き、**「Messaging API」** のチャネルをクリックします。
4. 画面上部のタブから **「Messaging API設定」** をクリックします。
5. ページの一番下までスクロールすると、**「チャネルアクセストークン（長期）」** という項目があります。
6. 右側の **「発行」** ボタン（すでに発行済みの場合は **「再発行」** またはコピー）をクリックします。
7. 表示された英数字の長い文字列（トークン）を**コピー**してメモ帳などに控えておきます。

---

## 🔷 ステップ2：GoogleスプレッドシートとGASを開く

1. ブラウザで [Google スプレッドシート](https://sheets.new/) を新規作成します。
   - シート名は「`神埼鉄道スタンプラリー管理台帳`」などお好きな名前に変更してください。
2. 画面上のメニューバーから **「拡張機能」 ＞ 「Apps Script」** をクリックします。
3. Apps Scriptのエディタ画面が開きます。
4. 元から書いてある `function myFunction() { ... }` をすべて削除して、画面を空にします。
5. このプロジェクトの `gas/Code.gs` のコードをすべてコピーして、エディタに貼り付けます。

---

## 🔷 ステップ3：トークンを入力して公開（デプロイ）する

### 1. トークンの入力
コードの12行目あたりにある以下の部分を探します：

```javascript
// ▼▼▼ ここを探してください ▼▼▼
const LINE_CHANNEL_ACCESS_TOKEN = '★ここにLINEのチャネルアクセストークンを貼り付け★';
```

`★ここにLINEのチャネルアクセストークンを貼り付け★` の部分を消して、**ステップ1でコピーしたトークンを貼り付けます**。

例：
```javascript
const LINE_CHANNEL_ACCESS_TOKEN = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...（長い文字列）...';
```
※ 前後の `'`（シングルクォーテーション）は消さないように注意してください。

### 2. 保存
画面上部の **フロッピーディスクマーク 💾（保存アイコン）** をクリックします。

### 3. デプロイ（公開）
1. 画面右上の青い **「デプロイ」 ＞ 「新しいデプロイ」** をクリックします。
2. 左側の歯車マーク ⚙️ をクリックし、**「ウェブアプリ」** を選択します。
3. 次の項目を設定します：
   - **説明**: `LINEスタンプラリー連携 v1`（何でもOK）
   - **次のユーザーとして実行**: `自分 (your-email@gmail.com)`
   - **アクセスできるユーザー**: **「全員」**（← ⚠️ ここを必ず「全員」にしてください！）
4. **「デプロイ」** ボタンをクリックします。
5. 「アクセスを承認」と出た場合は、ご自身のGoogleアカウントを選択し、「詳細」＞「（安全ではないページ）に移動」＞「許可」をクリックします。
6. デプロイが完了すると、**「ウェブアプリのURL」**（`https://script.google.com/macros/s/.../exec`）が表示されます。このURLを**コピー**します。

---

## 🔷 ステップ4：LINE DevelopersにURLを登録する

1. 再度 [LINE Developers Console](https://developers.line.biz/) の **「Messaging API設定」** タブを開きます。
2. **「Webhook設定」** の項目を探します。
3. **「Webhook URL」** の「編集」をクリックし、**ステップ3でコピーしたウェブアプリURLを貼り付けて「更新」** をクリックします。
4. **「Webhookの利用」** のスイッチを **ON（緑色）** にします。
5. 「応答メッセージ」の項目にある「編集」をクリックし（LINE Official Account Managerが開きます）：
   - **応答モード**: `チャット` または `Bot`
   - **あいさつメッセージ**: `ON`（任意）
   - **応答メッセージ（自動応答）**: **`OFF`**（⚠️ これがONになっているとGASと重複してしまいます）
   - **Webhook**: **`ON`**

---

## 🎉 テストしてみましょう！

1. スマホのLINEで、作成したLINE公式アカウントを友だち追加します。
2. トーク画面を開き、以下の文章のいずれかを送信してみてください：
   - `初級クリア済み`
   - `中級クリア済み`
   - `上級クリア済み`
3. 即座にLINE上にきれいな**クーポンカード（Flex Message）**と**引き換えコード（`KZ-EASY-200`など）**が返信されます！
4. さらに、Googleスプレッドシートに戻ると「**クーポン発行ログ**」シートが自動作成され、発行日時やユーザーIDが自動で記録されます。
5. 手に入れたコードを神埼鉄道アプリ内の「**LINE公式クーポンコード引き換え**」に入力すれば、アプリ内で特典が有効化されます！

---

## ❓ うまく動かない時のチェックリスト

- **Q. 返信が届かない**
  - LINE Developersの「Webhookの利用」がONになっているか確認してください。
  - GASのデプロイ時、「アクセスできるユーザー」を「**全員**」にしたか確認してください。
  - コード上部のトークンが正しく `' '` で囲まれているか確認してください。
- **Q. コードを修正したのに反映されない**
  - GASのコードを変更した時は、必ず **「デプロイ」 ＞ 「デプロイを管理」 ＞ 「鉛筆マーク（編集）」 ＞ バージョンを「新バージョン」** にして再デプロイしてください。
